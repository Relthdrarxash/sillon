Confidentialité

Dernière mise à jour : 10 novembre 2026.

En bref

Sillon ne collecte aucune donnée personnelle. Il n'y a ni compte, ni serveur, ni traceur, ni publicité, ni mesure d'audience. Votre potager, vos parcelles et vos réglages restent sur votre téléphone.

Internet

L'application ne déclare pas la permission Internet dans son manifeste Android. Elle est techniquement incapable d'envoyer ou de recevoir des données par le réseau.

Autorisations demandées

  • Notifications : uniquement pour les rappels de semis, que vous activez vous-même dans les réglages. Vous pouvez refuser cette autorisation sans perdre aucune autre fonction.

Localisation

Sillon n'utilise pas la localisation de l'appareil. Vous choisissez vous-même votre département, qui sert à estimer la date des dernières gelées.

Données conservées sur le téléphone

Le plan de votre potager et vos réglages sont enregistrés dans l'espace privé de l'application. Ils sont supprimés si vous désinstallez l'application ou effacez ses données.

Sauvegarde

La sauvegarde est un fichier que vous enregistrez vous-même à l'endroit de votre choix. Sillon ne l'envoie nulle part. Une copie dans votre compte Google est possible, mais désactivée par défaut : vous pouvez l'activer dans les réglages. C'est alors Android qui la fait, chiffrée de bout en bout avec le code de verrouillage de votre téléphone, de sorte que ni Google ni Sillon ne peuvent la lire. Elle n'est proposée qu'à partir d'Android 12, sur un téléphone verrouillé. Pour la restaurer sur un autre téléphone, Android demandera le code de l'ancien. Le transfert direct d'un téléphone à l'autre reste possible dans tous les cas.
